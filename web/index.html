THE HOUSE RULES

Easy to start.
Room to get better.

01

Use what you have.

Use each tile once per word. A blank can be any letter and adds zero points. Longer words aren’t always worth more.

02

Every find counts once.

Submit as many different words as you can before the clock runs out. Duplicate guesses don’t add points. Check the missed words after.

03

Keep it simple.

Scores are the sum of tile values, with no board bonuses. This is a practice tool with a demo word list, not an official Scrabble dictionary.
